# PC System Health Reporter

A beginner-friendly Python desktop application that collects basic PC system information and generates an easy-to-read HTML health report.

## Features

- Displays CPU information
- Monitors RAM usage
- Checks disk usage
- Displays battery information (where available)
- Checks internet connectivity
- Shows basic system health status
- Generates an HTML system report
- Simple desktop interface using Tkinter

## Technologies Used

- Python
- Tkinter
- HTML
- CSS

## Installation

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Install the required packages:

```bash
pip install -r requirements.txt
```

## How to Run

```bash
python gui.py
```
